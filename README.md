# TheNotepad

A minimalist black notepad app built using Electron.

The goal of this project: a distraction free text editor that feels lightweight and easy to use.

## Features
- Minimal black UI
- Custom title bar
- Keyboard shortcuts (Save / Open)
- Native file dialogs
- Packaged as a macOS app

## Tech
- Electron
- HTML, CSS, JavaScript
- Node.js (for file system access)
